## How It Works

### Review Process

1. **Initialization**:
   - Creates LangGraph ReAct agent with review tools
   - Initializes state with task context from inputs

2. **Review Loop** (ReAct pattern):
   - **Reason**: LLM decides what to check next
   - **Act**: Executes action (run command, read file)
   - **Observe**: Receives result from action
   - **Repeat**: Until review is complete

3. **Completion**:
   - Returns `AgentFinishAction` with structured findings
   - Includes summary, issues (critical/major/minor), test results, recommendation

### Tools Available

1. **run_command**: Execute shell commands
   - Run tests (`pytest`, `npm test`, etc.)
   - Run linters (`pylint`, `eslint`, etc.)
   - Run git commands (`git diff`, `git status`, etc.)
   - Any shell command for analysis

2. **read_file**: Read and analyze files
   - Examine specific files
   - Check code sections
   - Review changes

3. **finish_review**: Complete review
   - Provide summary
   - List issues by severity
   - Give test results
   - Make recommendation (APPROVE/REQUEST_CHANGES/NEEDS_DISCUSSION)

## Integration Points

### As a Standalone Tool

Test any codebase directly:
```bash
cd /path/to/OpenHands
python openhands/agenthub/langgraph_reviewer_agent/test_reviewer_standalone.py /path/to/code
```

### As a Delegate Agent

Can be called from CodeAct or other agents:
```python
from openhands.events.action import AgentDelegateAction

action = AgentDelegateAction(
    agent='LangGraphReviewerAgent',
    inputs={
        'task': 'Review the code changes',
        'focus': 'security',
        'run_tests': True,
    }
)
```

### In OpenHands Workflows

1. CodeAct makes changes to code
2. CodeAct delegates to LangGraphReviewerAgent
3. Reviewer examines changes, runs tests, checks for issues
4. Reviewer returns findings to CodeAct
5. CodeAct can address issues or present results to user

## Architecture

```
LangGraphReviewerAgent
├── LangChain LLM Adapter (bridges OpenHands ↔ LangChain)
├── LangGraph ReAct Agent (reasoning + acting loop)
├── Review Tools
│   ├── run_command (execute validation)
│   ├── read_file (examine code)
│   └── finish_review (report findings)
└── System Prompt (review guidelines)
```

## Advantages

1. **Systematic**: Uses ReAct pattern for thorough, step-by-step review
2. **Flexible**: Can review any codebase, not just OpenHands changes
3. **Standalone**: Can be tested independently of full OpenHands setup
4. **Extensible**: Easy to add new review tools and capabilities
5. **Integrated**: Works seamlessly with OpenHands event system
6. **Well-tested**: Comprehensive test suite included

## Limitations

1. Requires LangGraph dependencies (optional install)
2. Quality depends on LLM capabilities
3. May require multiple steps for thorough reviews
4. API costs for LLM calls
