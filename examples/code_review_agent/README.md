# Code Review Agent Example

This example demonstrates how to use the LangGraph-based Code Review Agent to automatically review generated code against a specification.

## Overview

The Code Review Agent uses:
- **LangGraph's ReAct pattern** for structured reasoning and action
- **Multiple validation tools** for code analysis
- **Configurable LLM** (supports OpenAI-compatible APIs)

## Prerequisites

1. Install the required dependencies:

```bash
cd /Users/ngc436/Documents/projects/OpenHands
poetry add langgraph langchain-openai langchain-core
```

2. Configure your `.env` file with the vLLM server settings:

```bash
# .env file in project root
GPT_OSS_HOST=http://your-vllm-server:8000/v1
GPT_OSS_KEY=your-api-key
GPT_OSS_MODEL_NAME=your-model-name
```

The example automatically loads these variables from `.env`.

## Running the Example

### Basic Usage

```bash
cd /Users/ngc436/Documents/projects/OpenHands
poetry run python examples/code_review_agent/run_review.py
```

### With Debug Logging

To see all agent reasoning steps and tool calls:


```bash
poetry run python examples/code_review_agent/run_review.py \
    --spec /path/to/your/spec.md \
    --code /path/to/your/code.zip \
    --module YourModuleName \
    --output /path/to/report.md
```

## Example Data

The example uses test data from the M4 module:

- **Specification**: `test_data/module_M4/M4.md` - Describes the VacancyService module
- **Generated Code**: `test_data/module_M4/M4_v1.1_run3_before_CR_1.zip` - Code generated by a coding agent BEFORE human review

Since this code is before human review, the agent should find several issues.

## What the Agent Does

1. **Reads the specification** to understand requirements
2. **Finds and analyzes all Python files** in the generated code
3. **Extracts class and method signatures** using AST
4. **Validates implementations** against the specification:
   - Signature matching (method names, parameters, return types)
   - Field access validation
   - Test quality analysis
5. **Reports issues** with severity levels and suggestions
6. **Generates a final report** in Markdown format

## Integration with Coding Agents

To use the review feedback in your coding pipeline:

```python
from openhands.agenthub.langgraph_reviewer_agent.integration import (
    generate_cr_feedback_for_agent
)

# Generate feedback formatted for a coding agent
feedback = generate_cr_feedback_for_agent(
    spec_path="/path/to/spec.md",
    code_root="/path/to/code",
    module_name="MyModule",
)

# Pass feedback to your coding agent
coding_agent.receive_message(feedback)
```

## Customization

### Using a Different Model

```python
from openhands.agenthub.langgraph_reviewer_agent import (
    CodeReviewAgent,
    ReviewAgentConfig,
)

config = ReviewAgentConfig(
    llm_model_name="gpt-4o-mini",  # or any OpenAI-compatible model
    llm_base_url="https://api.openai.com/v1",
    llm_api_key="your-key",
    temperature=0.0,
    max_iterations=20,
)

agent = CodeReviewAgent(config, debug=True)
result = agent.review(spec_path, code_root, module_name)
```

### Disabling Specific Validators

```python
config = ReviewAgentConfig(
    enable_signature_validation=True,
    enable_field_validation=False,  # Skip field validation
    enable_test_validation=True,
    enable_structure_validation=False,  # Skip structure checks
)
```
